Import dữ liệu để đối chiếu

File chỉ được đọc và lưu trong trình duyệt trên máy này, không gửi ra Internet. Khi xử lý xong, dashboard sẽ tự tải lại bằng bộ dữ liệu vừa chọn.

Không phụ thuộc thứ tự cộtBộ import dò theo tên tiêu đề trong 8 dòng đầu. Vì vậy file giáo viên không có cột “Lớp”, file có thêm “Số BHYT/Địa chỉ”, hoặc file đổi thứ tự cột vẫn đọc được. Tên cột bắt buộc phải giữ đúng nội dung như mẫu trên.
