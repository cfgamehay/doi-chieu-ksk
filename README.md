# Đối chiếu dữ liệu KSK

Dashboard tĩnh dành cho GitHub Pages. Repository chỉ chứa giao diện và giá trị băm kiểm tra mật khẩu. Dữ liệu nghiệp vụ nằm trong file `.ksk` mã hóa AES-256-GCM, được chuyển riêng và kéo thả vào trang sau khi đăng nhập.

Không đưa `data.js`, file `.ksk` hoặc các file Excel gốc vào repository này.
